# Library and dedicated-player refinement

The user supplied MP3-player/portable-player references. Reuse their functional hierarchy: focused square artwork, discrete source/format, title/artist, a thin timeline with separate elapsed/total labels, and restrained transport. Keep Pocket Music's existing dark-blue roles, licensed icons and font; no reference branding, photographs or promotional copy is copied. No spinning artwork, live blur or animation loop is added.

The saved-audio player is now a full-window native Dialog rather than an overlaid bottom sheet. A back/down action closes it without stopping playback. Artwork is bounded by screen height; content scrolls on compact/large-font screens. Shuffle/repeat flank Previous/Play/Next; Timer, Queue and Sound are secondary. Sound reveals volume. Current queue position is shown between time labels. Accessible descriptions expose icon purpose and toggle state. The official visible YouTube preview panel stays separate.

Library: local track/storage summary, a quiet Liked collection shortcut, a dedicated local title/artist filter, small Everything/Audio/Video chips, remembered sort, and Play all for the current audio selection. Rows retain artwork, clear metadata and an overflow. Search changes only local views and does not issue network requests. Download-folder management remains in Settings rather than occupying the track list.

Delete download is in each local track overflow. Cancel changes nothing. Confirm removes the validated app playback file, cleans its local history/favorite path and stops current native playback or removes an upcoming queue entry. Catalogue likes are preserved. The selected folder copy is kept by default; an unchecked optional checkbox explicitly requests deletion of the exact tracked SAF document. Other files/import sources are never searched/deleted. Missing permissions/folder errors are reported. Deletion is permanent, with re-download available, rather than an Undo claim. In-progress same-track jobs and active folder saving are guarded.

Verification: native interaction tests cover library filtering, player navigation, cancel/confirmed deletion of the current song, restricted library paths and history cleanup. An opt-in SAF test uses Android's real system picker and a dedicated emulator directory to verify both keep-copy and delete-tracked-copy behavior. No production account/download is needed.
