# Home artwork

`home-studio.png` is an original project asset generated with the built-in image generation tool on 25 October 2026. It is bundled locally. WPF decodes it at a maximum width of 1024 pixels, freezes the bitmap and brush, and adds no animation or network image requests.

Final prompt:

> Use case: stylized-concept. Create one polished original editorial artwork for the right-hand visual panel of Pocket Music, a dark Windows music application with soft lavender accents. Landscape 3:2 composition, high quality tactile 3D still life of a black vinyl record with a pale lavender center label, sculptural over-ear headphones, and a translucent curved sound-wave ribbon on a deep charcoal plinth. Warm off-white and muted lavender studio lighting, refined and atmospheric, subtle grain, real material depth, confident simple forms. Objects large and centrally composed to survive cropping into a wide panel. Background near-black charcoal. No lettering, no text, no logos, no UI, no watermarks. This is a standalone image asset, not a screenshot or interface mockup.

The piano, record and acoustic card illustrations are static, editable WPF shapes in Desktop.xaml.


app-icon.png is a PNG export of the existing PocketMusic.ico, used as the Windows media-session cover fallback when track artwork is unavailable.
