# Scope and limitations

No open failing regression in tested flows. This desktop reconstruction retains Pocket Music's local folder and official YouTube preview, not Spotify accounts, licensed catalog, subscriptions or personalized recommendation service. Suggestions are local history/title matches and guided query ideas; discovery runs real searches. Original cover graphics are fallbacks, not extracted album artwork.

Small windows collapse optional side content; users can deliberately reopen now playing. Existing official visible YouTube mini-player and Audio/Video behavior are retained. Live YouTube availability/extraction was not tested in this UI pass; its offline/error/control bridge was checked without network. Rea evidence is static and limited to Pocket Music's supplied DLL. This is a local review build, not a published stable release.
